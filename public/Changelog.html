Development Change Log

Documentation of version transitions, bug fixes, performance optimizations, and security updates.

v2.3.0 Active 2026-05-30
  • Usability Deployed the Platform Insights telemetry dashboard (Insights.html) showing code evolution metrics, threat records, and interaction heatmap.
  • Usability Integrated clear Developer Beta warning banners highlighting that the codebase includes a full-stack, classroom-enabled version featuring instructor controls, student audit tables, and secure auth.
  • Verification Corrected GenKit statements on the Systems page to accurately clarify the local static execution engine vs. the production GenKit/Gemini API roadmap.
  • Usability Implemented empathy-driven learning loops with randomized motivational coordinate praise and constructive math correction messages to guide students.
v2.2.0 Archived 2026-05-30
  • Aesthetics Re-themed coordinate grid from cyan to high-contrast glowing LED Red.
  • Accessibility Replaced low-contrast red axis numbers and labels with bright glowing white text for excellent WCAG legibility.
  • Aesthetics Centered a subtle, barely visible white school watermark "E" behind the grid lines.
  • Usability Streamlined guest view by hiding the classroom joining panels if the profile is not enrolled in a classroom.
  • Aesthetics Designed custom glowing LED School Maroon outline borders and shadow overlays for all active buttons.
  • Documentation Deployed custom Mission & Architecture timeline overview details page.
  • Accessibility Brightened formula container text in step-by-step modal.
v2.1.0 Archived 2026-05-30
  • Security Bypassed email and password authorization block on startup. The app is now open-access to everyone.
  • Security Patched Stored XSS vulnerability in student roster viewer. Inline execution strings (`onclick`) were replaced with secure dataset attributes and programmatically bound DOM event listeners.
  • Usability Added a Profile Settings Modal allowing users to define custom display names and swap roles (Student vs. Instructor) on the fly without registration requirements.
  • Quality Corrected point submission logic. Challenges with 1-point answers (e.g. `vtx-1` vertex, `sys-1` system intersection) are now validated correctly instead of defaulting to a 2-point requirement.
  • Accessibility Implemented live coordinate announcements using `aria-live="polite"` to provide audio feedback to screen readers during arrow-key grid navigation.
  • Accessibility Configured modal focus trapping and keyboard boundaries. Added support for closing modal settings and solutions using the `Escape` key.
  • Accessibility Boosted brightness of secondary text colors (`--tx3`) to `#8E8EAA` to comply with WCAG AA standard contrast ratios.
v2.0.0 Archived 2026-05-28
  • Migration Successfully ported the full-stack database application to a 100% serverless, client-side static build.
  • Migration Integrated a local `fetch` request interceptor overriding `window.fetch` to redirect API queries directly to `localStorage`.
  • Migration Nested the subproject within the `FuturisticLab` portfolio timeline card flow.
v1.0.0 2026-05-20
  • Initial Release: Established Node.js Express server backend connected to NeDB database.
