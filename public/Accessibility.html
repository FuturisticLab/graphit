Accessibility Standards

Graphit is designed to be inclusive and accessible to everyone. We have audited and updated the graphing lab to align with Web Content Accessibility Guidelines (WCAG 2.1 AA) standards.

1. Keyboard Grid Navigation

The coordinate graphing grid is fully navigable without a mouse. Users can focus the grid container and navigate the coordinate axes using arrow keys to place, review, and confirm points.

Move Grid Cursor Left / Right ← / →
Open Confirmation / Toggle Point Space or Enter

Cancel / Dismiss Dialogs Escape

2. Screen Reader Audio Feedback

  • Coordinate Announcements: The grid incorporates `aria-live="polite"` and `aria-atomic="true"` elements. As you move the cursor using keyboard arrows, the screen reader dynamically reads out coordinates (e.g. "(-2, 3)") instantly.
  • Interactive Labels: The canvas includes explicit descriptive `aria-label` tags outlining directions, shortcuts, and navigation bounds.
  • Alert Regions: Authentication errors, test submissions, and join room notices utilize active `role="alert"` boxes to notify screen reader users immediately when status text changes.

3. Focus Trap & Dialog Management

  • Focus Redirection: Opening settings, classroom managers, or solution modals immediately redirects focus to the dialog window.
  • Focus Containment: Modal overlays trap user focus using keyboard boundaries, preventing standard tab clicks from navigating background elements hidden under the modal.
  • Visual Indicators: Enhanced outlines (`:focus-visible`) have been implemented globally to highlight links, buttons, and text fields clearly for keyboard navigation.

4. Color Contrast Compliance

  • Text Boosting: The secondary text color variable (`--tx3`) has been brightened to `#8E8EAA` to resolve dark theme luminance limits.
  • AAA Contrast: All text-based instructions, math formulas, steps, and table cards satisfy a contrast ratio of `5.4:1` (exceeding the standard WCAG AA `4.5:1` requirement) on all background contexts.
