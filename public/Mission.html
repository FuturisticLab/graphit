Mission & Systems Architecture

A detailed overview of Graphit's operational objectives, software matrix, and system milestones.

"Graphit was initiated to resolve a critical gap: standard coordinate graphing applications frequently lack the robust accessibility features required for inclusive education. Designed over nine months of dedicated engineering, the system was originally built on a client-server infrastructure and has been released as a public preview to the Math & IB Chairman at MVRCS for testing, curriculum feedback, and accessibility auditing."

Evolution of the Lab

September 2025

Conception & Accessibility Mandate

Project initiated to resolve severe graphing and coordinate accessibility limitations in student educational platforms, commencing a nine-month engineering cycle.

May 20, 2026

v1.0.0 Client-Server Infrastructure

Deployed full Node.js Express server backend connected to NeDB databases for classroom tracking, student roster audits, and secure authentication.

Beta Release & Academic Review

Released the preview publicly to the Math/IB Chairman at MVRCS for curricular validation, pedagogical feedback, and accessibility testing.

Ported core files to a static portfolio subproject. Intercepted fetch API calls to route DB requests directly to local browser memory (localStorage) to allow serverless execution.

Removed password constraints to enforce open-access credentials. Implemented keyboard modal trapping, Escape listener hooks, and screen reader coordinate readouts.

Upgraded visual contrast by applying glowing LED-Red axes and coordinates, deep LED-Maroon button styling, and the watermark school emblem.

Google Developer Ecosystem

Graphit is developed under the Google Developer Program and is powered by Google's suite of developer tools. Our core architecture leverages Express, Node.js, and NeDB. In this local developer preview, mathematical step-by-step explanations and coordinate validation rules are pre-compiled and statically mapped locally in challenges.js to ensure latency-free, cost-free, and sandboxed execution. The production deployment roadmap integrates Google GenKit running on Pro-tier Gemini models for dynamic, real-time coordinate parsing and personalized mathematical guidance.
